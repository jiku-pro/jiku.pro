Our Products

Jiku's products support the advanced statistical analysis of continuum data.

Our main products are Jiku Core and Jiku UI (both in development). Our first fully released app is Jiku Power1D.

Jiku Core

Curated open-source suite of software tools for analyzing continua

  • Currently in development
  • Large suite of data processing, simulation and analysis tools
  • Supported by public and private research grants
  • Developed, maintained and curated by Jiku
  • Free for non-commercial use
  • Documentation available at jiku-core.org

Jiku UI

Desktop app, interface to Jiku Core

  • Currently in development
  • Point-and-click analysis of complex continuum data
  • Hypothesis testing, machine learning, stochastic sensitivity
  • Graphical analysis pipeline programming
  • Python scripting for interactive programming and batch processing
  • Available for Windows, Mac, Linux
  • Academic / non-profit pricing available

Jiku Power1D

Power analysis for 1D continuum data

  • Plan experiments and sample sizes
  • Interactively model 1D effect geometries
  • Conduct automated post hoc power analysis
  • See Tutorials for details
